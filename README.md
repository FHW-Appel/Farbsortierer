# Farbsortierer
Dieses Repository enthält alle notwendigen Dateien zum Nachbau einer Sortiermaschine für Bongbongs bzw. Bügelperlen. Enthalten sind die 3D-Druckmodelle für die mechanischen Komponenten, der Arduino-Quellcode zur Steuerung der Anlage sowie eine vollständige Bauteileliste (BOM). Das Projekt ermöglicht die automatisierte Sortierung von Perlen nach definierten Kriterien und dient als Grundlage für eigene Anpassungen und Weiterentwicklungen.
